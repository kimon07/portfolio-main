# AESOP Reimagined — 완성 작업

## 열기

이 폴더는 별도 빌드가 필요 없는 HTML/CSS/JavaScript 정적 사이트입니다.

- 시작 화면: `index.html`
- 현재 작업 환경 미리보기: `http://127.0.0.1:8080/aesop/`
- 포트폴리오의 AESOP 커버, 체험 iframe, 새 창 링크도 이 폴더로 연결되어 있습니다.
- 배포 시 `aesop` 폴더 전체(이미지, 폰트, JS, CSS 포함)를 포트폴리오와 함께 올리면 됩니다. `shoppingLIst.html`의 기존 대소문자를 유지하세요.
- 실제 결제·회원 인증·문의 전송 서버는 없습니다. 주문은 명시적으로 표시된 **주문 미리보기**이며, 계정 아이콘은 로그인 없이 사용하는 **내 컬렉션**으로 연결됩니다.

## 원본과 보존 범위

처음 제공된 작업 폴더에는 AESOP의 소개 화면과 스크린샷만 있었고, 사이트는 `https://octos8.github.io/Aesop-projects/`를 iframe으로 표시하고 있었습니다. 연결된 공개 원본 `https://github.com/octos8/Aesop-projects`를 이 폴더로 가져와 보완했습니다. 외부 원격 저장소에 push하거나 배포하지 않았습니다.

원본 커밋은 `5f8b9a27366ea4dfa8a7fe922b9a1cbca1913fe2`입니다. 가져온 원본 Git 기록은 작업 폴더의 `.aesop-tools/aesop-source-git`에 보관했습니다. AESOP 폴더가 중첩 Git 저장소로 취급되어 배포에서 빠지지 않도록, 사이트 파일은 일반 프로젝트 폴더로 통합했습니다.

기존 메인 배너, 컬렉션 슬라이더, 프로모션 레이아웃, 제품 카드 구조, 선릿 보태니컬 바디 밤의 상세 이미지, 공통 헤더·푸터의 스타일을 유지했습니다. 추가 스타일은 `css/completion.css`, 공통 동작은 `js/site.js`에 분리했습니다.

## 발견 사항과 처리

| 발견 사항 | 보완 결과 |
|---|---|
| 제품 목록의 모든 카드가 동일한 제품으로 이동 | 41개 제품의 고유 `purchase.html?id=…` URL과 제품별 이름·이미지·가격·옵션 연결 |
| 카테고리는 이동만 하고 필터링하지 않음 | 카테고리·NEW·BEST SELLER 필터, 정렬, 검색, URL 및 뒤로 가기 대응 |
| 모바일에서 전체 상품을 끝없이 나열 | 초기 6개, PC/PAD 초기 12개와 실제 동작하는 더 보기 |
| 검색·로그인·장바구니 아이콘의 빈 링크 | 검색, 내 컬렉션, 장바구니 화면 구성 |
| 장바구니 담기는 알림만 표시 | 옵션·수량·선물 포장·쿠폰을 저장하고 목록 수정·삭제·합계 계산 |
| 쿠폰 버튼은 다운로드 문구만 변경 | 5% 적용/해제 및 상세·장바구니·주문 합계 일치 |
| 구매 확인 이후 진행 불가 | 주문 미리보기 → 완료 → 내 컬렉션 기록까지 연결 |
| 최근 본 제품은 항상 비어 있음 | 실제 열어본 제품을 저장하고 관련 탭과 내 컬렉션에 표시 |
| 관심 상품은 새로고침하면 초기화 | 브라우저에 저장하고 다른 페이지에서도 조회 |
| 문의 작성은 준비 메시지만 표시 | 입력 검증, 작성 모달, 제품별 문의 메모 저장·조회 |
| ABOUT와 하위 메뉴·푸터의 연결 누락 | 브랜드 이야기, 철학, 지속가능한 일상, 저널, 고객 안내 화면 구성 |
| 프로모션 제품/세트가 일반 목록으로 이동 | 각 상품/세트 상세와 구성품 목록으로 연결 |
| 메인 배너가 모두 프로모션 첫 화면으로 이동 | 숲·아침·밤의 해당 섹션 앵커로 정확히 연결 |
| 일부 카테고리 이미지의 제품/브랜드 불일치 | 프로젝트 내부의 해당 제품 이미지로 교체 |
| 중복 모바일 메뉴 이벤트 | 공통 header.js로 통합, 열기·닫기·재클릭·Escape·키보드 포커스 순환 |
| 작은 모바일 메뉴 터치 영역 | 최소 44px 터치 영역과 읽기 쉬운 메뉴 크기 |
| 맨 위로 버튼이 구매 버튼 위에 겹침 | 스크롤 위치와 구매 영역 표시 여부에 따라 노출 |
| 슬라이더가 외부 CDN에 의존 | 기존 Swiper 12를 로컬에 보존, 이전·다음·자동 재생 제어 추가 |
| 폰트가 외부 CDN에 의존 | 기존 Pretendard 파일과 라이선스를 로컬에 보존 |
| footer.html / together.html의 깨진 상대 경로 | 공통 스타일이 연결된 독립 안내·추천 화면으로 복구 |
| 임시 canonical/OG 주소 | `your-domain` 임시 메타데이터 제거 |

## 콘텐츠와 이미지

- 새 이미지 생성이나 외부 이미지 핫링크 없이 기존 `img` 리소스를 재사용했습니다.
- 상세 화면은 제품 히어로, 제품 이야기, 향/원료의 콘셉트, 텍스처, 제품 유형에 맞는 사용 리추얼, 추천·최근 본 제품을 제공합니다.
- 향수·핸드·바디·스킨·헤어·홈의 설명과 사용 리추얼을 구분하고, 세트에는 구성품 목록을 추가했습니다.
- 선릿 상세의 기존 화보 이미지를 보존하고, 작은 화면과 접근성을 위해 HTML 설명·아코디언도 덧붙였습니다.
- 콘셉트 제품/가격/성분 모티프와 예시 후기는 포트폴리오 내용임을 표시했습니다. 실제 효능이나 공식 전성분으로 소개하지 않습니다.
- 정적 프로젝트에서 실제 주문이나 상담이 완료되었다는 거짓 상태를 표시하지 않습니다.

## 데이터와 유지보수

- 단일 제품 데이터: `js/catalog.js`
- 공통 기능, 목록, 상세 콘텐츠, 검색, 장바구니, 내 컬렉션: `js/site.js`
- 기존 상세 갤러리·수량·탭·아코디언 기능: `js/purchase.js`
- 기존 헤더·모바일 메뉴: `js/header.js`
- 기존 슬라이더와 추가 제어: `js/main.js`
- 추가/수정 반응형 스타일: `css/completion.css`
- 브라우저 저장소 키는 `aesop.` 접두어를 사용하여 포트폴리오의 다른 프로젝트와 분리했습니다.
- `support.html#privacy`에서 사이트 저장 데이터를 지울 수 있습니다. 문의 메모에 개인정보를 입력하지 않도록 안내합니다.
- 원본의 `js/product.js`, `js/product-control.js`, `js/tgt.js`는 보존하되 활성 페이지에서는 로드하지 않습니다. 기능은 새 공통 카탈로그/저장소로 통합했습니다.
