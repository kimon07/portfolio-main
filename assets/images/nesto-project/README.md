# NESTO portfolio case study
Entry: portfolio menu → NESTO PROJECT; standalone: nesto.html.
nesto-preview.html is a responsive design prototype, not a checkout-enabled store.
Original ONDO files are unchanged. All image assets are local.

Built-in image_gen generated assets:
- hero.png: Photorealistic cream rounded boucle sofa with orange side table, warm yellow-orange studio backdrop, natural sunlight, no text, wide composition.
- spaces.png: Exact 4 x 2 image sheet; cream living room, oak dining room, ivory kitchen, ivory bedroom, orange chair, cream sofa, orange table, oak sideboard; bright natural light, pale oak floors, cream walls, no text. Displayed using CSS background positions.
Both files are in assets/nesto/. Image generation prompts specify a warm, bright, cozy, modern and playful furniture brand.

Case-study cover screenshots (local storefront, not generated mockups):
- showcase-desktop.png: `nesto-shop/index.html`, desktop home at 1440 × 1280.
- showcase-mobile.png: `nesto-shop/index.html`, mobile home at 390 × 1050.
The responsive composition in `nesto.html` / `nesto.css` places these actual screens together with the NESTO wordmark. Refresh the screenshots when the storefront changes.
