# NESTO storefront

기존 오렌지 캠페인, 로고, 공간 중심 메인 구성과 크림·우드 분위기를 유지한 정적 가구 쇼핑몰입니다.

## 구성

- `index.html`: 공간별 쇼핑, 실제 상품과 연결된 스타일링, 베스트 상품, 신상품, 시즌 컬렉션, 예시 리뷰, 브랜드 이야기
- `list.html`: 공간·카테고리·컬러 필터, 검색, 추천·인기·신상품·가격·할인율 정렬, 페이지 이동
- `product.html?id=0`부터 `id=24`: 상품별 상세 정보, 네 가지 이미지, 옵션·수량, 찜, 장바구니, 연관 상품, 리뷰, 문의
- `js/catalog-data.js`: 25개 상품의 고정 ID, 가격, 옵션, 소재, 치수, 배송·관리 정보
- `js/review-data.js`: 서로 다른 본문 125개로 구성한 명시적 예시 리뷰. 평점은 리뷰 별점에서 계산
- `nesto-shop.js`: 공통 렌더링과 인터랙션, 로컬 저장소 상태
- `storefront-polish.css`: 기존 스타일을 유지하는 상품·편집 콘텐츠·반응형 보완
- `img/catalog/`: 대표 이미지 25개와 제품별 3장 갤러리 스트립 25개. 총 50개 WebP, 100개 제품 장면
- `image-prompts.json`: 내장 image_gen 제작 방식, 최종 이미지 경로, 제품별 생성 프롬프트와 수정 기록

이미지는 밝은 크림 벽, 우드, 자연광을 공통으로 사용합니다. 갤러리는 대표 제품을 참조하여 전면·소재·다른 각도를 연결했습니다. 테이블·펜던트·거울의 디테일은 판매 제품에 초점을 맞추도록 재검수했습니다. 기존에 있던 원본 이미지와 다른 포트폴리오 페이지는 보존했습니다.

## 실행

프로젝트 루트를 정적 웹서버로 제공하고 `nesto-shop/index.html`을 열면 됩니다. 외부 패키지 설치나 빌드 과정은 필요하지 않습니다. 상위 포트폴리오의 NESTO iframe 연결과 `nesto:navigate` 메시지를 유지합니다.

## 검수 — 2026-10-02

Microsoft Edge / Playwright, PC 1920px · PAD 1024px · MOBILE 402px.

- 총 123개 페이지·뷰포트 조합: 메인, 목록, 네 가지 공간, 일곱 가지 카테고리, 25개 상품 상세, 검색 대안, 유효하지 않은 상품 ID
- 가로 넘침 0, 깨진 이미지 0, 로컬 리소스 요청 오류 0, JavaScript 실행 오류 0
- 각 상품 카테고리 최소 3개, 상품별 대표 이미지 중복 없음
- 모바일 전체 메뉴와 Escape 닫기, 검색, 컬러 필터, 가격 정렬
- 이미지 갤러리와 확대, 찜과 도움이 돼요의 새로고침 후 유지
- 컬러·케어 키트·수량이 반영된 장바구니, 쿠폰 계산, 체험 주문, 게스트 주문 조회·취소
- 문의 저장, 배너 이전·다음, 메뉴 URL 응답, 브랜드·가이드·푸터 대화상자
- 대표 이미지와 갤러리 전체 육안 검수, 화면 크기별 스크린샷 검수

작업공간의 `.duck-check/nesto-audit.cjs`와 `.duck-check/nesto-final/audit.json`에 재현용 검수 코드와 결과가 있습니다.

## 운영 범위

가상 브랜드 포트폴리오입니다. 상품·배송 정보와 리뷰는 예시이며 결제·출고·회원 인증·서버 접수는 연결하지 않았습니다. 찜, 장바구니, 닉네임, 주문과 문의는 현재 브라우저의 `nesto-shop-v2` 로컬 저장소에만 보관됩니다. 사이트 이용 안내에서 기록을 초기화할 수 있습니다. 옵션의 다른 컬러는 주문 정보에 반영되며 이미지는 대표 컬러 기준임을 표시합니다.
